# QG-SFM 机制与检索收益不一致的原因剖析

日期：2026-11-05。仅分析，不修改训练源码。

## 判断

现有证据更支持“方案提供的注意力偏置与 UAD 表征/任务之间缺少足够互补作用”，
并可能被掩码语义误差及全局参数折中抵消；目前不支持把主因定为代码漏接、参数未更新或训练数值崩坏。
这是有证据排序的解释，不是已经完成因果定位。

首先需要准确界定现象：相对真实四卡 UAD，mAP −0.02、R1 +0.25、R5 +0.22、R10 −0.37 个百分点。
这是总体接近基线的混合变化，不能从一个 seed、0.02 个百分点诊断出“分割必然有害”。
但也没有达到通过空间先验改善整体检索的实验目标，值得检查设计假设。

## 一、实现符合方案，不代表方案已满足研究目标

当前检查链条是：逐图对应的 mask → 同步几何增强 → 128 维 coverage → 12 层非原地 QG 调制 →
原 final norm → 仅 CLS → CE/WRT/ProCA/GPD；测试也继续提供 mask。

代码、之前的正确性测试及真实日志支持以下判断：

- QG 标量在优化器中且持续更新，R 非零，模块并未被静默绕过。
- mask/image 的拼接顺序一致，每个模态有自己的 mask，没有用 RGB mask 作为三模态共用输入。
- 前向特征和损失接到方案规定位置，原型库与 AMP/恢复路径能继续运行。
- 训练 120 轮完成，8/13704 次 AMP 跳步不构成持续训练失效。

这些是计算正确性和运行证据；它们不能证明人体区域分割正确、mask 空间信息有效、
Query 门控优于 soft-SFM，或最终身份表征更具跨场景泛化能力。

“代码修改不彻底”需要有明确遗漏作为证据。当前没有发现这种证据。
没有加入 STR/CHI、前景池化和新损失是 guide 的明确边界，不能事后把这些设计选择说成代码漏改。
同时不能排除服务器的个别样本关联/语义问题：文件存在、尺寸正确、二值编码正确，并不证明分割对象正确。

## 二、正向前景调制还改变了前景内部排序强度

对有效前景 Query、两个纯前景 Key，当前公式给出：

S'_j = (1−α)S_j + αM。

因此 S'_u−S'_v = (1−α)(S_u−S_v)。

α>0 时，前景相对背景可能得到优待，但前景内部高低 logits 差异会压缩；
这两个效应同时发生，不能只描述为“增强人体”。
Re-ID 需要区分同样属于人的不同区域，不能假定头部、衣服、背包、腿部都应更均匀地参与聚合。
其真实影响需要查看 attention 和检索难例，不能只靠直觉判断。

当前最后记录的 12 层 α 全部为负，说明优化后没有维持统一的正向前景拉齐。
α<0 会扩大纯前景内部差异：例如 α=−0.19 对应约 1.19 倍的差异。
这是与“模型更需要保留/突出已有高响应前景区域”相容的信号，但不是已证明的唯一原因。

更严格地，对某一相同原始分数 S 的前景与背景 Key，令 t=(S−m)/(M−m)，
二者增量差（除以 M−m）是 α(1−t)+βt。
以日志第 1 层 α=−0.188101、β=0.177631 为例，交叉点 t≈0.5143。
相同原始分数在低于这一行范围约 51.4% 的位置时，前景未必比背景更有利。
因此仅看到 β>0 也不能推断最终前景质量必然改善。

第 6、12 层 α、β 同时为负时，对纯前/背景 Key，前景 logits 下调而背景 logits 上调。
这可能是上下文利用、掩码漏分后的全局适应，或其他训练偏好，不能直接宣称它在逐图纠错。
这种作用是否改善泛化尚未得到验证。

若 mask 为全前景，softmax(S')=softmax((1−α)S)，机制退化成温度调节。
因此非零参数和非零 R 仍然不自动构成人体空间信息被利用的证据。
R08 既有抽样不是普遍全图，所以不能反过来推断本次全部收益缺失都由全图 mask 导致。

## 三、新增 Query 门控与 CLS-only 读出的作用路径有限

必须区分 SFM 调制本身和“QG 相对 soft-SFM 多出来的 Query 门控”。
SFM 本身直接改变 CLS attention，已经接到最终描述子；没有断路。

但 CLS 的 p_i=1，同输入同参数时：

ΔQG−Δsoft = vβ(1−p_i)(S−m)。

所以 CLS 行上的差值严格为零，差异集中在 coverage 小于 1 的 patch Query。
这部分额外效果要沿“patch Query 更新 → 后续层 CLS 聚合”传递。
最后一层在输入固定时，改变其他 Query 行不会改变同层 CLS 输出。

本轮补充的 CPU 小型模型验证也吻合此关系：
同参数 QG 与 soft-SFM 在单个 block 后的最终 CLS 完全相同；两个 block 后才出现非零差异。
该验证只证实路径，不用其差异幅度估计真实 ViT 的门控强弱，也不能说多层门控必然无用。

当前只有 CLS 身份读出，没有直接使用 foreground token 聚合形成独立身份补充。
这是方法连接上需要重点检验的地方，而不是少写了某个参数传递。
STMI 后续还有 token 重分配和交互，不能把它的整个下游表征过程当作当前 CLS-only 的等价物。
也不能因此直接迁入依赖多模态联合输入的融合方案，改变当前单图检索部署协议。

## 四、输入空间位置标签不等于深层 token 的纯语义标签

当前所有层使用同一张输入 mask。token 仍有位置锚点，但从第一层全局 self-attention 开始，
每个位置的表示都能混入其他位置的内容。
前景位置 token 可以包含背景上下文，背景位置 token 也能包含人体信息。

所以深层 p_i=0 并不证明该 Query 的表示只含无用背景；持续按固定几何标签保护/调制它，
需要与深层语义交互相协调。这个观察不能否定所有 ViT 空间先验，
但说明当前方案不能仅凭“输入位置属于背景”来证明所有层中对应 Query 都应保持原样。
soft-SFM vs QG 的同条件训练正是检验该假设的可执行办法。

## 五、coverage 和非空检查不是质量自适应

coverage 表示 patch 中被分成前景的面积比例，不是该 patch 属于正确人体的置信度。
一个完全被误分成前景的背包/遮挡物可以有 coverage=1；一个正确的人体边界 patch 可以只有 0.3。

valid 只检查增强后非空，不检查人体完整性。QG 中的 Q 是 Query，不是 Quality。
已有 R08 人工复核中存在只分背包、头部局部、中心提示落入背景等实例，
这些非空错误会继续影响训练和测试。

然而，错误影响并不等于图像证据被直接删除：原图仍输入 backbone，背景 Query 仍保留原 attention，
还有残差与 MLP。其结果可能是收益被抵消，也可能由主干补偿，不能一律解释为严重破坏。

每层两个标量在所有模态、平台、身份与图像间共享。面对正确 RGB mask 与不可靠 Thermal mask，
它没有独立的逐图纠错自由度。主干仍可通过输入相关的 Q/K/V 适应，不能说整个网络完全不能适应；
但全局标量本身的负值不构成逐图质量判断。

## 六、分割定位与跨模态身份对应是不同问题

人体分割回答哪里是人；跨平台多模态 Re-ID 还要解决视角、尺度、模糊、遮挡和光谱响应改变后，
不同图像中的哪些证据能稳定指向同一个身份。

完整轮廓不自动产生头部/躯干/腿部的语义对应，也不自动连接 RGB 颜色与 Thermal 响应。
因此即使 mask 完全正确，只有全局 attention 偏置也可能不能提供 UAD 尚缺少的判别信息。

四项损失仍然在最终 global CLS 上约束分类、排序和中心关系。
当前没有实验证明额外空间先验通过这一读出改善了跨域身份一致性。
最终 CE/WRT/ProCA/GPD 及训练准确率几乎与 baseline 相同，与“主干吸收了新增偏置、
但没有增加足够检索互补性”的解释相容；仅凭 loss 曲线不能证明表征逐维相同。

缺少新损失不等于设计错误，也不意味着解决办法必须增加损失。
首先应确定有价值的区域信息能否进入最终描述子。
另外，不能从 ProCA 的加权数值小，直接推断其梯度小或与其他损失发生冲突；
梯度大小/方向需要单独测量，当前没有这样的证据。

## 七、优化与数值问题的优先级

新增参数同 base LR、零 weight decay、全局 clip。相同 LR 保持与 baseline 的主训练协议对齐，
不保证新标量的优化尺度天然最佳；但现有数据也不足以把 LR 定为主因。
部分 α 接近 −0.2，表示有强负偏好和一定 tanh 压缩；第 6 层导数约 0.091，不是完全无梯度。

因此目前不优先采用：改主学习率为 0.008、强制系数非负、扩大 bound、延长到 200 轮，
或同时修改原有 WRT/ProCA/GPD。它们会混入新变量，也未直接检验上述结构假设。
少量 AMP 跳步和已经接续完成的恢复，同样不是当前无明显收益的首要嫌疑。

## 八、如何区分原因，避免凭指标猜测

先用现有权重对少量 RGB/NIR/TIR × 地面/航拍样本做一次诊断，不重新生成全部 mask：

1. 对增强后图像、coverage 网格和样本路径做对应可视化，区分数据关联错误与语义误分割。
2. 在相同层、相同输入下，同时计算原 logits 的 attention 与调制后的 attention，
   分别记录 CLS→前景 patch、CLS→背景 patch、CLS→CLS 的注意力总量（attention mass），以及各 head 的分布。
   前景 patch 统计须排除 CLS 本身，避免把 p_cls=1 的自注意力当成人体关注。
3. 按真实可见人体分割的好/坏程度、模态与平台分组，看收益是否集中于可靠 mask；
   用 coverage 或 SAM 预测分数直接当真值会形成循环论证。
4. 同时观察 CLS 行的实际 attention 变化；全矩阵 R 不能替代它，
   logits 的相对 RMS 改变也不能换算成前景 attention mass 或检索提升。

这些是内部机制诊断，不关闭正式测试中的 QG，不替代规定测试协议。
即使对已训练模型临时换 mask 做敏感性实验，其结果也受分布变化影响，不能替代重新训练的消融。

之后用已有 QG 结果作为 A，补两项同条件训练：

|实验|只改变什么|回答的问题|
|---|---|---|
|B：uniform coverage|每图保留面积比例，消除 patch 空间分布|空间定位是否有额外价值|
|C：soft-SFM|取消额外 Query 门控，其他保持|背景 Query 保持原样是否有帮助|

解释规则：

- A≈B：没有空间信息贡献的证据，优先修正空间先验利用方式。
- A>B：空间 mask 有价值，再查为什么只改善部分 Rank-1，及 mask 质量差样本是否抵消收益。
- C>A：保护背景 Query 的假设在当前 CLS 架构中不占优，属于设计选择需修订。
- A>C 且 A>B：两种假设有支持，再评估剩余性能瓶颈与重复性。

历史 baseline 的主要训练协议已对齐，但测试 batch 与 AMP/恢复实现有差异。
若要对零点几个百分点做严格因果归因，还需当前同版本 QG-off 对照与重复性检查。
目前不把多 seed 当作绕过空间/Query 两个核心消融的手段。

## 九、依据诊断选择修订方向，而不是一次重写方案

如果确认问题在“前景拉齐压缩身份细节”，一个小改动候选是区域加性偏置，
例如 ΔS_ij=vγ p_i p_j。对纯前景 Key，它保留原来的组内分数差；
全前景时退化为行常数，对 softmax 不产生影响。
这是针对此公式问题提出的待验证替代，不是已实现或已验证更好的方法。

如果确认空间信息有价值，但 CLS-only 的收益出口不充分，则考虑保留原 CLS 全局路径，
用可控残差方式加入前景 token 的身份信息，仍为每图输出一个描述子。
这属于需要更新 guide、单独消融的新版本设计，不能称为补上原本漏写的代码。
掩码不可靠时还要处理区域信息可靠性，简单再加一个前景分支不能保证有效。

这两个方向针对不同原因，不应同时加进同一次实验，再把结果归因其中任意一个。

当前最有依据的结论是：计算路径基本符合方案，而“空间先验→更好的跨场景身份表征”
这一设计假设尚未得到证明。应先辨别空间信息、Query 门控、读出方式和掩码质量各自的作用，
再作最小必要修订；不能把已有的计算自检当作检索收益的证明。
