## 模块和数据衔接

1. 每图按相对路径读取自身原尺寸掩码，不按 PID 共享。校验尺寸、单通道、编码和存在性，错误直接报错。
2. 掩码规范化为 0/1，与图像同步 Flip/Pad/Crop；掩码 nearest resize、padding=0；图像保持 UAD 插值、归一化、随机擦除。擦除不修改语义掩码。
3. 几何增强后 16×16 平均池化，得到 16×8=128 覆盖率，展平顺序与 PatchEmbed 一致。三模态图像/覆盖率/有效性按相同顺序拼接，PKM 身份连续分组与 target.repeat(3) 保持一致。
4. CLS 权重=1；增强后空掩码令 v=0，关闭该图调制。近全图合法掩码仍有效。
5. 12 层共享 ViT-B，每层两个 head 共享标量，共新增 24 个可学习参数；调制发生于 QK^T 后、scale/softmax 前。QKV/Value/残差/MLP/CLS 路径不变。

\[
\Delta S_{ij}=vp_i[\alpha_l p_j(S_i^{max}-S_{ij})-\beta_l(1-p_j)(S_{ij}-S_i^{min})].
\]

\[
A=softmax((S+\Delta S)/\sqrt{64}),\qquad O=AV.
\]

alpha/beta=0.2*tanh(raw/0.2)，raw 零初始化，允许正负。FP32 计算调制，行极值保留梯度，非原地相加，再转回 logits dtype。空 batch 和零参数不提前返回，保留 DDP 梯度图。

最终仍为 768 维 pre-BN CLS；CE 用 BNNeck 后分类结果；WRT 用未 L2 归一化的 pre-BN；ProCA/GPD 沿用原归一化、中心 detach、原型 EMA。

\[
L=L_{CE}+L_{WRT}+0.01L_{ProCA}+L_{GPD}.
\]

QG 参数独立 optimizer group，base LR 相同、weight decay=0，共用 scheduler 和全局梯度裁剪。未加入新损失、STR/CHI、文本分支或可靠性网络。

## 功能验证及解释边界

|检查|结果|边界|
|---|---|---|
|原 UAD vs QG 零初始化|12 层 attention/block、CLS、BNNeck、分类输出 FP32 完全一致|不是训练后等价|
|空间调制|正系数增加前景 Query 对前景 Key 的总概率；非零参数改变完整模型输出|不保证分割前景是真实人体|
|Query 门控|背景 Query 的本层 logits 不直接改变|多层特征仍可间接受影响|
|四项损失各自反传|各自能到达调制参数，梯度有限且非全零|不要求每层每 batch 非零|
|空掩码及多卡|一 rank 全空/所有 rank 全空，Gloo 反传和同步通过|不是 NCCL 实测|
|预训练加载|合成权重、位置插值、QG 保持零值、缺权重拒绝加载通过|没有真实 ImageNet 文件|
|30 张真实原图和 R08 PNG|正式管线→128 覆盖率→完整 ViT-B→768 CLS 通过；零参数等价，非零参数改变输出|随机骨干权重，不能评估检索|

全部 token 为前景时，注意力等价于 softmax((1-alpha)*S/sqrt(d))，不等于关闭调制；已增加极限测试。当前没有按面积/SAM 分数自动判定语义质量，也没有把困难样本自动填为全前景。本轮固定使用 R08 原结果作为弱先验；质量回退是独立研究变量。

alpha/beta 跨图片、模态和平台共享，不是逐图质量判别器。正负系数由训练学习，不能保证始终增强真实人体。零初始化和有界参数也不保证长训练不会退化。

## 服务器执行顺序

服务器工程根为 /project/code/WHU_base/WHU_STMI。本地 WHU/ 内文件同步到服务器根对应位置，不额外套一层 WHU/。

### 1. wsam：复核 300 张正式输出

```bash
conda activate wsam
cd /project/code/WHU_base/WHU_STMI
CUDA_VISIBLE_DEVICES=0 python tools/generate_sam2_masks.py \
  --image-root /project/code/data/WHU-MARS \
  --mask-root /project/code/data/WHU-MARS_masks_R08_v1_check300 \
  --selection /project/code/data/WHU-MARS_masks_validation_v3_selection.json \
  --prompt-rule R08_box_center \
  --checkpoint /project/code/third_party/sam2/checkpoints/sam2_hiera_large.pt \
  --model-config configs/sam2/sam2_hiera_l.yaml --precision bf16 --resume

python tools/verify_mask_equivalence.py \
  --generated-root /project/code/data/WHU-MARS_masks_R08_v1_check300 \
  --reference-root /project/code/data/WHU-MARS_masks_validation_v3 \
  --rule R08_box_center \
  --report /project/code/data/WHU-MARS_masks_R08_v1_check300/equivalence.json
```

要求 checked=300、identical=300、mismatches=[]。有差异先定位，不覆盖旧 v3，不重新人工选规则。

### 5. 正式训练

目标批量短步通过后使用原 train.py。示例四卡（仍需与 baseline 实际 batch 一致）：

```bash
CUDA_VISIBLE_DEVICES=0,1,2,3 torchrun --standalone --nproc_per_node=4 \
  train.py --config_file configs/UAD.yml \
  MODEL.DIST_TRAIN True MODEL.PRETRAIN_PATH "$PRETRAIN" \
  DATASETS.MASK_ROOT /project/code/data/WHU-MARS_masks_R08_v1 \
  DATASETS.MASK_MANIFEST /project/code/data/WHU-MARS_masks_R08_v1/manifest.json \
  SOLVER.IMS_PER_BATCH 256 SOLVER.BASE_LR 0.008 SOLVER.SEED 1234 \
  OUTPUT_DIR logs/UAD_QG_SFM_R08_1000_DDP
```

单卡继续 python train.py、MODEL.DIST_TRAIN False，例原设置 SOLVER.IMS_PER_BATCH 64，同样先验证显存。

1000 完整训练 120 轮，同一最终模型评测 1000/1000GD，1000GD 不单独训练；2337 后续独立训练。冒烟不保存权重，正式训练从同一 ImageNet 初始化重新开始。训练和测试都读取冻结掩码，不加载 SAM。

观察参数更新、有效调制 R、是否长期饱和、四项 loss 及各协议 mAP/Rank-1/mINP；不要把参数非零或 loss 下降等同于检索收益。
