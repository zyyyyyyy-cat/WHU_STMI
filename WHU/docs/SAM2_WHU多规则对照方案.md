# WHU-MARS SAM2多规则对照方案

本轮在训练集固定72张上，一次比较多种提示/输入规则与候选选择方式。不修改UAD、QG-SFM公式、四项损失或正式掩码。所有规则在比较前固定；不逐图手工选结果拼成所谓最优算法。

## 为什么需要针对WHU，而不只是更换一个点

| 数据特点与已见现象 | 具体风险 | 本轮处理 |
|---|---|---|
| 很多地面裁剪图中行人大致居中，但有遮挡、多行人和车辆 | 图像中心可能落在遮挡物/背景；单点可能只选衣物局部 | 中心/偏上点、多前景点、框对照；仍保存全部候选 |
| 航拍俯视、斜姿态、宽高比不固定 | 竖直人体点列可能离开人体 | 紧凑点组、温和二维框对照；竖直方案也在航拍组实测，不预设有效 |
| 原图小至24×36，运动模糊和遮挡明显 | 原始信息不足，精细轮廓难以确认 | 优先审阅人体主体及Patch层面错分；不靠超分辨率虚构细节 |
| IR中人体可能亮也可能暗，夜间低对比度 | 固定灰度阈值/亮区=人体不成立 | 不使用亮度直接分割；只增加单独的IR百分位拉伸对照 |
| Thermal为伪彩图，背景和其他热源也会亮 | 颜色不是可直接读取的物理温度，也不保证人体最亮 | 保留原三通道输入，不套IR灰度阈值，不反推温度 |
| v1出现整图近白与高分背景误选 | 全图框与最高预测IoU的组合不可靠 | 去框、收缩框、补白、负点等对照；拆开提示与候选选择的影响 |
| 裁剪很紧，人体可接触边界 | 边缘负点和边界占用惩罚可能误伤人体 | 负点与启发式仅为待比较方案，保留无负点/纯SAM分数对照 |

不能由这些特性推导某条规则一定最好。当前缺少人工像素级真值；不把SAM分数、面积合适或轮廓平滑当成真实分割精度。

## 固定的15类提示/输入规则

所有坐标先在原图归一化到[0,1]，再乘(W-1,H-1)。框为XYXY。绿色点是前景提示，红点是背景提示，黄色线为提示框。

| 编号 | 规则 | 主要检验的问题 |
|---|---|---|
| R00 | v1整图框+[.5,.5]中心点，multi | 重现已有对照并保存全部候选 |
| R01 | 仅中心点，multi | 移除整图框能否减少整图退化 |
| R02 | 仅[.5,.35]偏上点，multi | 中心落在腿间/遮挡时，偏上提示能否改善；也可能只选上身 |
| R03 | [.5,.25],[.5,.5],[.5,.75]三前景点，multi | 多部位约束能否减少只分局部；航拍可能违背该先验 |
| R04 | [.5,.5],[.4,.5],[.6,.5]紧凑三点，multi | 放宽竖直站立假设；可能落到邻近背景 |
| R05 | 中心正点+四角负点，multi | 显式背景约束能否抑制整图前景 |
| R06 | 竖直三正点+四角负点，multi | 同时约束完整性与背景；有边界误伤风险 |
| R07 | 仅框[.10,.02,.90,.98]，multi | 移除点歧义，轻微排除左右背景；可能截手臂 |
| R08 | R07框+中心点，multi | 对照R07，区分点与框的协同 |
| R09 | 框[.08,.08,.92,.92]+中心点，multi | 更均衡的二维先验能否适配俯视图；紧裁剪可能截身体 |
| R10 | 仅中心点，single | 单输出与多候选输出是否有差异 |
| R11 | 竖直三正点，single | 多提示情形下single是否优于multi |
| R12 | 常色补白+中心点，multi | 增加画外上下文/改变SAM归一化比例是否有帮助 |
| R13 | 常色补白+原图范围框+中心点，multi | 原图框不再等于完整输入框，能否减少整图候选 |
| R14 | 仅IR：灰度1/99百分位拉伸+中心点，multi | 低对比度输入是否限制SAM；RGB/Thermal不运行此规则 |

四角负点坐标为[.02,.02],[.98,.02],[.02,.98],[.98,.98]。常色补白为每侧 `round(.12*max(W,H))` 像素，至少1像素，颜色取原图四边RGB中位数。补白图上推理后严格裁回原图坐标；不会把补白区域保存进正式大小的mask。

R14是输入对照，不是用亮度直接生成掩码；低于1%、高于99%的值截断，中间线性映射，仍需SAM推理。伪彩Thermal不做这一变换。没有加入随意更换色表、反色、固定热阈值或超分辨率；这些会引入新的、尚未证实的语义假设。

## 候选与排序分开比较

每条multi规则保留SAM返回的全部3个候选，single保留1个。对同一候选组生成两种结果：

1. `__iou`：选SAM预测IoU最高的候选，作为原始排序。
2. `__geometry`：预先固定的启发式排序：

```text
rank = q + 0.20*positive_hit - 0.20*negative_hit
         - 0.15*border_coverage - 0.30*extreme_penalty

extreme_penalty = max(0,(area-0.85)/0.15) + max(0,(0.03-area)/0.03)
```

`positive_hit`/`negative_hit`分别是所给正/负提示点被mask覆盖的比例；若没有该类提示点则该项为0。`border_coverage`为图像四边的前景占比。所有量在裁回原图后计算。候选仍不做任何像素修改；不会取反、膨胀、按面积清零或关闭QG。若所有候选都差，排序仍会选出一个并保留证据，不将其伪装成“有效人体”。

这些权重只是公开、固定的诊断起点，尚未证明有效，不能当作分割可靠性估计。完整人体接触边界时，几何惩罚可能让局部mask胜出，因此必须对照原始候选。两种排序选中同一候选很正常，single的两种结果必然相同；不将这些重复结果当作独立研究改进。

## 执行

同步两个文件到服务器的 `WHU/tools/`：

- `compare_sam2_rules.py`（新增）；
- `generate_sam2_masks.py`（已有，用于通用哈希和掩码检查）。

```bash
conda activate wsam
cd /project/code/WHU_base/WHU_STMI/WHU

CUDA_VISIBLE_DEVICES=0 python tools/compare_sam2_rules.py \
  --image-root /project/code/data/WHU-MARS \
  --selection /project/code/data/WHU-MARS_masks_preview_v1/preview_selection.json \
  --output /project/code/data/WHU-MARS_masks_rules_v2 \
  --checkpoint /project/code/third_party/sam2/checkpoints/sam2_hiera_large.pt \
  --model-config configs/sam2/sam2_hiera_l.yaml \
  --precision bf16
```

中断后增加 `--resume`，要求provenance一致，并验证已完成图像的候选、选中mask和预览文件。不要多个进程同时写同一output。不需要安装新分割模型或修改clipreid。

72张包括24张IR：应得到2064条选中结果、2808个原始候选mask、每图两张总览（72张selected总览+72张candidates总览）。它们来自15类规则与两种排序，不是2064次独立图像编码。每图native编码复用12套提示，padding编码复用2套，IR另外编码1次对比度输入，总计168次编码、1032次解码调用。实际耗时和峰值显存待服务器测量。

```text
WHU-MARS_masks_rules_v2/
  provenance.json          # 规则、排序权重、代码与权重哈希、选图清单
  results.jsonl            # 每规则/排序的选中候选、全部候选统计
  summary.json             # 各规则/排序×六场景的统计；IR增强只统计IR
  records/                 # 每图完成标记，用于续跑
  candidates/              # 全部候选，原图大小0/255 PNG
  masks/                   # 各规则与排序选择的mask；仅本轮训练集样本
  review/selected/         # 每图各规则两种排序的叠加总览，带提示位置
  review/candidates/       # 每图全部候选的叠加总览，带提示位置
```

上传给助手：

```bash
tar -czf /project/code/data/WHU-MARS_masks_rules_v2_review.tar.gz \
  -C /project/code/data/WHU-MARS_masks_rules_v2 \
  review provenance.json results.jsonl summary.json
```

## 如何判断，而不是简单看谁的面积更合适

第一轮仍逐图、分六场景比较：主要人体是否保留、背景误选/整图退化是否减少、肢体是否大范围遗漏、邻人/车辆/遮挡物是否合并。允许小孔洞和少量边缘误差；针对QG-SFM还应关注16×8覆盖率层面是否区分人体与背景，而非只追求平滑轮廓。

`summary.json`统计极端面积等症状，不是无真值的自动排名。评估时先分别看六组，再看规则是否同时改善不同组；IR增强只能和IR组比较。没有证据前不把某模态专属规则硬编码为最终策略。

若正确人体已在候选池中但排序选错，下一步改选择规则；若候选池整体无合理轮廓，则调整提示/分割器，而不是继续堆排序惩罚。若小图普遍无法可靠分割，应明确承认空间先验质量的限制。

72张已被用于方案设计，是开发样本，不是独立验证集。选出少量候选规则后，在未参与本轮设计的新训练集图像上复核，尽量避开同身份近邻帧；必要时对少量代表图标注粗人体区域/掩码，才可比较真实分割精度。规则冻结后全量处理train/query/test，不用测试检索结果调提示或逐图挑选候选。

本地已通过2项合成检查（提示坐标、排序、编码复用、所有分支保存、原图尺寸、统计和预览输出）。本地未运行真实SAM2/CUDA，不预先宣布任何规则有效。
